# Depression Prediction using Machine Learning

## Project Overview
This project was developed as my BCA Major Project with the objective of predicting the likelihood of depression using machine learning techniques. The system analyzes user-related data and identifies patterns associated with depressive symptoms, helping in early awareness and decision support.

The project follows a complete machine learning pipeline including data preprocessing, feature selection, model training, and evaluation. Multiple algorithms were implemented and compared to analyze their performance and accuracy.

The final model generates predictions based on input features and demonstrates how machine learning can be applied in the healthcare domain for mental health awareness. This project was developed strictly for academic and learning purposes and does not replace professional medical diagnosis.

- Logistic Regression  
- Decision Tree Classifier

## Dataset
The dataset used in this project contains user-related attributes associated with mental health indicators. It was preprocessed to handle missing values and improve model performance.
